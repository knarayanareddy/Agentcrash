A model may propose.
A deterministic system decides.

A support agent reads an untrusted customer message and proposes a refund. SAAF decides whether that proposal can reach a ledger, needs human review, or must be blocked. If the agent's policy or memory drifts, SAAF quarantines it and restores a healthy checkpoint.

Why

Support agents are being handed tools that move money.

Air Canada

Chatbot gave wrong bereavement-fare information. A tribunal ordered the airline to pay C$812.02.

DPD

Assistant was provoked into abusive output. The company disabled the AI element of its chatbot.

Replit

A development agent deleted production data. The CEO confirmed it publicly.

Three different failures, one shape: a fluent model, slightly wrong about what it is allowed to do. These incidents are the motivation — not a claim that SAAF prevents every class of AI incident.

The loop

untrusted customer message
  → ONE model call → structured PROPOSAL (never an invocation)
  → deterministic policy guard over TRUSTED server-side facts
  → drift audit + judgment layer
  → runtime capability allowlist
  → server-owned dispatcher → mock ledger   (the only side effect)
  → customer reply rendered from an APPROVED TEMPLATE
  → replayable workpaper   (zero model calls)

The model never calls a tool

It returns data. A server-owned dispatcher decides whether the one permitted action runs, and refuses everything else before dispatch.

Trusted facts vs untrusted text

Order totals, evidence status and claim type come from the server. The model may read them; it can never supply them.

The reply is never free-form

Customer-facing text is rendered from a template tied to the outcome and the policy clause that produced it.

Blocked is not the same as review

Above the order total: blocked. Above the cap: not prohibited, a supervisor may approve. Conflating them is how engines start lying.

The policy

Synthetic, versioned and hashed. It is not any real company's policy.

RuleDispositionClause

Scope and limits

  • The policy is synthetic — not any real company's policy.
  • Human review is a simulated local record, not a staffed handoff.
  • The workpaper seal means consistency-checked and replayable — not a signature, not proof of authorship, not certified compliance.
  • Three fixtures, not a benchmark. These are not a success rate.
  • “Simulated exposure prevented” is a simulation, not money saved.
  • No real payment was ever made. external_payment_executed is structurally always false.
